# Download After Dark

## Source ZIP (always latest `main`)

**Direct download:**

https://github.com/clubberLang222/after-dark-game/archive/refs/heads/main.zip

Or on the repo page: **Code → Download ZIP**

## Clone

```bash
git clone https://github.com/clubberLang222/after-dark-game.git
cd after-dark-game
npm install
npm run build
npm start
```

Open http://127.0.0.1:5173/  
Admin password: **afterdark**

## One-click helpers (in this repo)

- Windows: `Install-and-Play.bat` or `Start After Dark.vbs`
- Mac/Linux: `Install-and-Play.sh`

Requires [Node.js LTS](https://nodejs.org).
