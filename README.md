# After Dark

Premium party board game — React + Vite + TypeScript.

```bash
npm install && npm run dev
# or production:
npm run build && npm start
```

Admin: `afterdark`

## Features
48-space boards · 3D textures · preference / items / acts menus · Exhibitionist deck · media vault · LAN / TV cast
