# After Dark — Core Installer (Master)

Windows entry points for the After Dark product.

## PC game

| File | Action |
|------|--------|
| **Start After Dark.vbs** | Double-click → npm install, build, run |
| **Install-After-Dark.bat** | Same via Command Prompt |

Requires [Node.js LTS](https://nodejs.org). Opens **http://127.0.0.1:5173/**

## Android (same Wi-Fi)

| File | Action |
|------|--------|
| **Start After Dark Android Host.vbs** | Host PWA for phone |
| **INSTALL-AND-RUN.bat** | CMD variant |
| **host-for-android.mjs** | LAN server port 8080 |

Phone Chrome → Phone URL → **Install app**.

Separate Android ZIP: https://github.com/clubberLang222/after-dark-android/archive/refs/heads/main.zip

Master rule: installers deliver one After Dark game — not a separate engine.
